# Contact Manager Pro - Guia de Uso

Bem-vindo ao Contact Manager Pro, uma aplicacao elegante para gerenciar seus contatos pessoais de forma segura e intuitiva.

## Comecando

### Autenticacao

A aplicacao utiliza autenticacao exclusivamente via Manus OAuth. Para acessar:

1. Clique no botao "Fazer Login" na pagina inicial
2. Voce sera redirecionado para o portal de autenticacao Manus
3. Apos autenticar-se, voce retornara a aplicacao com sua sessao ativa

## Funcionalidades Principais

### Dashboard

Apos fazer login, voce sera levado ao dashboard inicial que exibe:

- Uma mensagem de boas-vindas personalizada
- Um card de acesso rapido para "Meus Contatos"
- Botao de logout no canto superior direito

### Gerenciar Contatos

Clique em "Meus Contatos" ou use a navegacao lateral para acessar a pagina de gerenciamento de contatos.

#### Criar um Novo Contato

1. Clique no botao "Novo Contato"
2. Preencha os campos obrigatorios (Nome)
3. Preencha os campos opcionais (Email, Telefone, Endereco)
4. Para buscar endereco automaticamente pelo CEP:
   - Digite o CEP no campo "CEP"
   - Clique no botao "Buscar"
   - Os campos de endereco serao preenchidos automaticamente
5. Clique em "Criar Contato" para salvar

#### Visualizar Contatos

A pagina de contatos exibe uma tabela com todos os seus contatos, mostrando:

- Nome
- Email
- Telefone
- Cidade

#### Buscar Contatos

Use a barra de busca no topo da pagina para filtrar contatos por:

- Nome
- Email
- Telefone

A busca eh em tempo real e atualiza a lista conforme voce digita.

#### Editar um Contato

1. Clique no icone de editar (lapis) na linha do contato
2. Modifique os campos desejados
3. Clique em "Atualizar Contato" para salvar as alteracoes

#### Visualizar Detalhes

1. Clique no icone de visualizar (olho) na linha do contato
2. Uma modal sera aberta mostrando todos os detalhes do contato
3. Clique fora da modal ou no botao de fechar para voltar

#### Deletar um Contato

1. Clique no icone de deletar (lixeira) na linha do contato
2. Uma confirmacao sera solicitada
3. Clique em "Deletar" para confirmar a delecao

## Recursos de Seguranca

### Isolamento de Dados

Cada usuario pode visualizar e gerenciar apenas seus proprios contatos. O isolamento de dados eh garantido em todas as operacoes.

### Busca de CEP

A integracao com a API ViaCEP permite buscar automaticamente o endereco completo (rua, bairro, cidade, estado) a partir do CEP informado.

## Dicas de Uso

- Sempre preencha o campo "Nome" ao criar um contato
- Use a busca para encontrar rapidamente contatos especificos
- O CEP deve conter 8 digitos para a busca automatica funcionar
- Todos os dados sao salvos automaticamente apos confirmacao
